# Customer Churn Analysis & Risk Dashboard

## Project Overview
This project analyzes customer churn using Power BI and Excel.
The dashboard provides insights into customer demographics,
subscription services, contract types, and churn patterns.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Analysis
- Customer churn rate
- Customer demographics
- Subscription services
- Contract types
- Payment methods
- Customer risk analysis

## Dashboard
The Power BI dashboard provides interactive visualizations
to identify customer segments and understand factors associated
with customer churn.

## Project Objective
To analyze customer data and create an interactive dashboard
that helps understand customer churn and identify customers
who may be at higher risk of churn.
